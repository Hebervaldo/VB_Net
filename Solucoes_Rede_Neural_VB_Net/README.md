# Soluções de Redes Neurais em VB.NET

Projeto desenvolvido em VB.NET voltado para implementação, estudo, treinamento e experimentação de redes neurais artificiais utilizando algoritmos próprios e estruturas matemáticas desenvolvidas manualmente.

A solução foi criada com foco em aprendizado de inteligência artificial, processamento matemático, manipulação matricial e desenvolvimento independente de modelos neurais, sem utilização direta de frameworks externos de machine learning.

O projeto possui arquitetura modular orientada a objetos, permitindo testes computacionais, simulação de aprendizado supervisionado, experimentação algorítmica e evolução contínua das estruturas neurais implementadas.
