# Soluções de Rede Neural em VB.NET - CoreNet

Aplicação desenvolvida em VB.NET para implementação, treinamento, experimentação e simulação de redes neurais artificiais.

O projeto foi criado com foco em desenvolvimento próprio de algoritmos de inteligência artificial, permitindo estudo de redes neurais, processamento matemático, treinamento supervisionado e experimentação computacional sem dependência de frameworks externos de machine learning.

A solução possui arquitetura modular orientada a objetos, voltada para processamento numérico, manipulação matricial, simulação de aprendizado, treinamento neural e análise de comportamento de modelos neurais.
